<h1>Active Directory Home Lab </h1>

<h2>Description</h2>
In this lab, Active Directory is deployed on Windows Server 2022 to establish a domain. The server is configured with DNS to provide domain name resolution and DHCP to distribute network settings to clients. PowerShell is used to automate the process of creating users in AD. Finally, a Windows 10 client is joined to the domain to validate AD authentication, DNS resolution, and DHCP configuration.
<br />


<h2>Languages and Utilities Used</h2>

- <b>PowerShell</b> 
- <b>VirtualBox</b>

<h2>Environments Used </h2>
- <b>Windows Server 2022</b>
- <b>Windows 10</b>
